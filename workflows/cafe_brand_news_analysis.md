# 네이버 카페 게시판 반응 분석 (브랜디드 '브랜드 소식')

## 목표
패션 커뮤니티 카페의 게시판 글을 기간 전체로 모아, 어떤 브랜드·어떤 글이 반응(조회·댓글·좋아요)을 얻는지 분석하고 **PDF 보고서**로 만든다. 목적은 미치코런던 남성복 런칭 때 실행할 콘텐츠 찾기.

- 대상: 브랜디드 카페(번호 27877258) '브랜드 소식' 게시판(메뉴 6) — https://cafe.naver.com/f-e/cafes/27877258/menus/6
- 첫 분석: 2026-10-11, 기간 2024-01-01 ~ 2026-10-11, 글 7,784개

## 순서
Python은 `%USERPROFILE%\.local\bin\python3.14.exe`, 한글 출력은 `PYTHONIOENCODING=utf-8`. 외부 패키지 없음.

| 단계 | 명령 | 결과 |
|---|---|---|
| 1. 수집 | `python tools/cafe_fetch.py --start 2024-01-01` | `.tmp/cafe/articles_27877258_6.json` (약 5분, 156쪽) |
| 2. 분석 | `python tools/cafe_analyze.py` | `.tmp/cafe/analysis.json`, `.tmp/cafe/brand_map.json` |
| 3. **Claude 해석** | 분석 결과와 상위 글을 읽고 `.tmp/cafe/insights.json` 작성 | 핵심 발견·공통점·추천 |
| 4. 보고서 | `python tools/cafe_report.py` | `output/브랜디드_브랜드소식_분석_날짜.pdf` |
| 5. 점검 | `.tmp/cafe/report.html`을 Edge 헤드리스로 캡처해 확인 | 글자 깨짐·표 잘림 |

- 다른 게시판·카페: `--cafe 번호 --menu 번호`. 시험은 `--max-pages 2`.
- 수집이 끊기면 같은 명령을 다시 실행(이어받기). 날짜를 새로 받으려면 `.tmp/cafe/state_*.json`을 지움.
- 조회수는 수집 시점의 누적값 → 다시 분석할 때는 1단계부터 새로.

## 수집 원칙
- 네이버 카페는 접근 규칙(robots.txt)으로 자동 수집을 금지함. **2026-10-11 사장님 지시로 이 분석에 한해 진행.** 매거진 수집 도구(`common.get_text`)의 robots 검사는 그대로 두고, 카페 도구만 따로 둠. 다른 카페·게시판으로 넓힐 때는 사장님께 먼저 확인.
- 정직한 이름표, 요청 사이 1.5초, 로그인·쿠키 사용 안 함(공개된 목록만).
- 거부(401/403/429)되면 재시도하지 않고 멈춤 → 받은 기간을 사장님께 보고.
- 받는 것은 목록의 숫자와 제목·본문 앞 300자(해석용)뿐. 사진·본문 전체·댓글 내용은 받지 않음.
- **수집 데이터와 PDF는 공개 저장소에 올리지 않음** (`.tmp/`, `output/` 모두 gitignore). 회원 글 제목이 들어 있음.
- 수집 범위(기간·개수)를 줄일 때는 사장님께 먼저 확인.

## 분석 기준 (`tools/cafe_analyze.py` 위쪽 숫자)
- **브랜드 이름**: 제목 맨 앞 `[브랜드]`. 영문/한글 표기 차이·오타·협업 표기(`A X B`)는 그 계정이 가장 자주 쓰는 이름으로 합침. 어떤 계정의 주 브랜드인 이름만 독립 브랜드로 인정. 합친 내역은 `brand_map.json` → 같은 브랜드가 둘로 갈렸는지 눈으로 확인.
- 카페 운영진 글(`OPERATOR` = 브랜디드)은 브랜드 순위에서 제외.
- 글당 평균·중앙값은 올린 지 7일 지난 글만. 브랜드 순위는 글 10개 이상.
- **반응률** = (댓글 + 좋아요) ÷ 조회수.
- **반응 좋은 브랜드 종합 점수** = 글당 조회 중앙값·글당 댓글 중앙값·반응률의 순위 백분위 평균. TOP 30은 최근 12개월 글 3개 이상인 브랜드만.
- **성장**: ① 작년 대비(해마다 글 8개 이상) ② 최근 6개월 vs 그 전 6개월(기간마다 5개 이상) ③ 새로 등장(첫 글이 최근 18개월 안, 글 5개 이상). 조회수가 누적값이라 '올린 직후 속도'는 측정 불가 — 보고서에 반드시 적을 것.
- **콘텐츠 유형**: 제목 단어로 자동 분류(`TYPES`). 한 글이 여러 유형에 들어감.

## 해석 작성 (`insights.json`, Claude)
항목: `findings`(핵심 발견 5개), `notes`(절마다 한 문단: monthly, brand_total, top_posts, score, rate, growth, newcomers, types, timing, titles), `patterns`(잘 되는 글의 공통점), `recs`(추천 — title, what, why, title_ex), `donts`, `rhythm`, `check`, `limits`.
- 숫자는 `analysis.json`에 있는 것만 인용. 표와 문장의 숫자가 맞는지 확인.
- 추천은 미치코런던 남성복 기준으로, 근거가 된 실제 글과 숫자를 함께.
- 글 내용에서 짐작한 것(브랜드끼리의 관계 등)은 '~로 보임'으로 쓰고 한계 항목에 적음.

## 알아둘 것
- 유니온블루는 카페 운영진과 같은 계정들이 글을 올림(홈그라운드 효과) — 숫자 목표로 삼지 말 것.
